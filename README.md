# API de Charadas

API REST para armazenar, consultar e sortear charadas, com autenticação, documentação Swagger e persistência no Firebase Firestore.

## Funcionalidades

- Listagem e consulta de charadas
- Sorteio de charada aleatória
- Autenticação por token
- Operações administrativas protegidas
- Documentação OpenAPI/Swagger

## Como executar

Crie um arquivo `.env` com as credenciais necessárias e execute:

```bash
pip install -r requirements.txt
python app.py
```
